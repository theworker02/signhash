# signhash

Sign CSV/TSV hash tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/signhash/

## Install / run

```bash
git clone https://github.com/theworker02/signhash.git
cd signhash
node src/cli.js
node --test
```
